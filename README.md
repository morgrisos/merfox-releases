# MerFox 配布リポジトリ

ここは **MerFox の公式バイナリ配布先** です。
最新版とこれまでの版は [Releases](../../releases) ページから入手できます。

## 対応環境

- macOS（Apple Silicon / arm64）

Intel 版 Mac、Windows には対応していません。

## インストール方法

1. [Releases](../../releases) から、最新版の `MerFox-<バージョン>-arm64.dmg` をダウンロードします。
2. ダウンロードした `.dmg` をダブルクリックして開きます。
3. 表示された **MerFox** を、隣の **Applications**（アプリケーション）フォルダへドラッグします。
4. アプリケーションフォルダの MerFox をダブルクリックして起動します。

Apple Developer ID で署名し、Apple の公証（notarization）を受けています。
公証の記録はアプリとディスクイメージの両方に添えてあるため、通常はそのまま起動できます。

セキュリティの設定を変える操作や、ターミナルでのコマンド入力は必要ありません。
そうした手順をすすめる案内を見かけた場合は、実行せずにサポート窓口へご確認ください。

はじめてお使いになる前に、同じ Release に置いてある
**「最初にお読みください」（`MerFox-ReadMeFirst-<バージョン>.html` または `.pdf`）** をご確認ください。

## ダウンロードしたファイルの確認（任意）

各 Release には `SHA256SUMS.txt` を置いています。
ダウンロードしたファイルが壊れていないかを確かめたい場合にお使いください。

ターミナルで、ダウンロードした `.dmg` のある場所で次を実行します。

```
shasum -a 256 MerFox-0.3.2-arm64.dmg
```

表示された値が `SHA256SUMS.txt` に書かれている値と同じであれば、ファイルは壊れていません。
この確認は任意です。行わなくてもインストールできます。

## 更新について

MerFox が自動で更新することはありません。
最新版の有無は、アプリの「設定」画面にある **「GitHubで最新版を確認」** から、いつでもご自身で確認できます。

## このリポジトリについて

ここは配布物（ビルド済みアプリ）を置くための場所です。
**MerFox のソースコードを公開するリポジトリではありません。**

## 困ったときは

アプリの「設定」画面にある「サポート資料フォルダを開く」から、
「困ったときの最初の確認」と「不具合報告テンプレート」を開けます。

解決しない場合は、販売担当者または案内されたサポート窓口へご連絡ください。
**ライセンスキーの全文やパスワードは送らないでください。**
